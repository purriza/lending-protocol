# Lending Protocol Scripts

This directory contains the essential utility scripts for the lending protocol project, organized by functionality.

## 📁 Directory Structure

```
scripts/
├── gas/                          # Gas-related scripts
│   └── gas-snapshot.sh           # Run gas snapshot tests
├── size/                         # Size-related scripts
│   └── size-check.sh             # Check contract sizes and enforce limits
├── deploy/                       # Deployment-related scripts
│   ├── configure-contracts.sh    # Configure deployed contracts
│   ├── deploy-contracts.sh       # Deploy contracts to network
│   ├── deploy-mocks.sh           # Deploy mock contracts to network
│   └── upgrade-contracts.sh      # Upgrade deployed contracts
└── export-deployments.sh         # Export deployment artifacts and update NetworkAddresses.sol
```

## 🚀 Quick Start

Use the scripts directly:

```bash
# Gas and Size Management
./scripts/gas/gas-snapshot.sh
./scripts/size/size-check.sh

# Deployment (requires network configuration)
./scripts/deploy/deploy-contracts.sh
./scripts/deploy/configure-contracts.sh
./scripts/deploy/upgrade-contracts.sh

# Export Deployments
./scripts/export-deployments.sh
```

## 🚀 Deployment Workflow

### 1. Deploy Contracts
```bash
# Deploy all contracts to the target network
./scripts/deploy/deploy-contracts.sh
```

### 2. Configure Contracts
```bash
# Configure deployed contracts with proper settings
./scripts/deploy/configure-contracts.sh
```

### 3. Upgrade Contracts (when needed)
```bash
# Upgrade existing contracts to new versions
./scripts/deploy/upgrade-contracts.sh
```

### 4. Export Deployment Artifacts (Automatic)

**Note:** The export is now automatically executed after successful deployments, upgrades, and configurations. You only need to run it manually if you want to update artifacts without deploying.
```bash
# Export ABIs, addresses, and update NetworkAddresses.sol
./scripts/export-deployments.sh
```

### Prerequisites
- Set up environment variables for the target network
- Ensure you have the necessary permissions and funds
- Verify network configuration before deployment

## 🔄 CI/CD Integration

**Note:** Only gas and size management scripts are run in CI/CD. Deployment scripts are for manual execution.

These scripts are automatically run in GitHub Actions on:
- Push to `main` branche
- Pull requests to `main` branche

The CI pipeline will:
- Run gas snapshot tests to ensure functionality
- Check contract sizes and fail if any contract exceeds the 24KB limit

**Deployment scripts are NOT run in CI/CD** - they require manual execution with proper network configuration and permissions.

## 📦 Deployment Export Script

### `export-deployments.sh`

This script exports deployment artifacts and updates NetworkAddresses.sol after contract deployment.

#### What it does:
1. **Build Contracts**: Runs `forge build` to compile all contracts
2. **Export ABIs**: Extracts contract ABIs from `out/` to `deployments/abi/`
3. **Export Addresses**: Aggregates deployed addresses from `broadcast/` to `deployments/addresses/`
4. **Update NetworkAddresses.sol**: Updates the Solidity file with current addresses (if found)

#### Prerequisites:
- **Node.js**: Required to run the export script
- **Foundry**: Required to build contracts (`forge build`)

#### Generated Files:
- `deployments/abi/` - Contract ABIs in JSON format
- `deployments/addresses/` - Deployment addresses by chain ID
- `deployments/index.json` - Summary of exported artifacts
- `script/config/NetworkAddresses.sol` - Updated Solidity addresses (if exists)

#### Manual Execution:
```bash
# Build contracts
forge build

# Export deployments
node tools/export-deployments.js
```

#### Committing Changes:
```bash
git add deployments/ script/config/NetworkAddresses.sol
git commit -m "🚀 Update deployment addresses and NetworkAddresses.sol"
```

#### Security Features:
- Path traversal prevention
- Input sanitization
- File type validation
- Base directory restrictions
- Regex injection prevention

#### Troubleshooting:
- **"Invalid contracts directory" warning**: Normal if `contracts/` directory doesn't exist or is empty
- **"NetworkAddresses.sol not found" warning**: Normal if the file doesn't exist yet
- **Permission errors**: Make sure the script is executable: `chmod +x scripts/export-deployments.sh`
